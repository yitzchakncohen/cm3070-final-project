# Welcome to the Modular Vehicle Physics System!

Here are some tips for getting started:

* **Explore the Demo Scene:** Run the `DemoScene` (`Assets/Scenes/DemoScene.scene`) to inspect example vehicles, controls, and configurations.
    * **WebGL Demo** (password cm3070): https://sir-yitz.itch.io/modular-physics-simulator
* **Review Creation Instructions:** Check out the `vehicleCreation.md` file for a step-by-step guide on creating a new vehicle.
* **Use Runtime Configuration:** Leverage the runtime vehicle configuration UI to update vehicles in real-time while testing them.
* **Enable Debugging Tools:** Use the debugging manager to toggle various debugging gizmos and UI elements on or off.
* **Control the Weather:** The weather system manages environmental settings and can be randomized directly from the runtime screen.
* **Check Dependencies:** By default, the package uses the **Universal Rendering Pipeline (URP)** and the **Unity Input System**.
